# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in `laravarc/authorizer`, please report it privately.

**Do not** open a public GitHub issue for security reports.

Email **security@laravarc.dev** or open a private GitHub security advisory.

Include a description, steps to reproduce, affected version(s), and potential impact.

We aim to acknowledge reports within 48 hours and share an initial assessment within 5 business days.
